AIニュース自動追跡システムの構築

「単なる件数記録」から「LLMによる週次要約」へ。ノイズを排除し、情報過多に陥らずに主要トレンドを効率把握するための検証フェーズ記録。 検討期間が終了したら結果を公開予定。

ステータス: 試行運用中 データソース: 日本経済新聞 (nikkei.com) 更新周期: 毎日自動収集 / 30日ローテーション

1. 構築の目的と運用の課題意識

当初検討していた手法の問題点

  • ５紙を跨ぐ検索ではPR記事や市況・株価などの「ノイズ」が多発する
  • 単に「記事件数」をカウントするだけでは定性的なトレンドが見えない
  • 日々何十件もの記事タイトルを目視確認・分類するのは持続不可能

本システムの目指す形

  • 情報の網羅性の高い日本経済新聞（`nikkei.com`）情報を一本化して収集する
  • 収集とデータ整理（30日後の自動破棄）は GitHub Actions で完全自動化する
  • 週末に集約されたタイトル群を LLM（Gemini等）で週次要約しインサイト抽出する

2. システム構成と運用ワークフロー

01

日次自動収集（GitHub Actions / Python）

毎日定時にスクリプトが起動。Google News RSS経由で日経新聞内の重要AI発表記事（新モデル・新機能等）を取得。

完全自動
02

CSV積載 ＆ 30日自動ローテーション

タイトル群を番号付き改行テキストとして `ai_news_stats.csv` に追加（約100件/日）。30日を超過した古い履歴はスクリプト側で自動破棄し、データ膨張を防止。

メンテナンスフリー
03

週1回の LLM（AI）による要約・インサイト抽出

週末に1週間分（過去7行）のタイトル欄をコピーし、LLMにプロンプト投入。「今週の重要トピック Top 3〜5」を抽出し整理する。

週1回（数分）

3. 設計上の工夫と取りこぼし防止（仕様検討）

厳選した検索クエリのチューニング

主要ベンダー名（OpenAI, ChatGPT, Gemini, Claude, Copilot, Meta等）と「新モデル」「新機能」「発表」などのキーワードを組み合わせつつ、-intitle:株 -intitle:市況 -intitle:PR -intitle:プレスリリース により宣伝・市況ノイズを徹底排除。

RSS取得件数上限（100件）と関連度順アルゴリズム

Google News RSSは注目度・関連度の高い記事を上位に優先配置する仕様であるため、100件の上限が存在しても「最重要ニュース」が下位に追いやられて漏れるリスクは極めて低い。また、日経新聞に絞り込んだことで1日の該当数は通常数件〜十数件程度に収まり、取得漏れを抑え込んでいる。

4. 現在稼働中のコアスクリプト (`script.py`)

取得したデータをLLMへ渡しやすくするため、番号付き改行形式でCSVに格納し、30日以上の過去データを安全にパージするロジックを含んでいます。 

import datetime
import urllib.parse
import feedparser
import pandas as pd

PAPERS = {"nikkei": "nikkei.com"}
KEYWORDS = '(OpenAI OR ChatGPT OR Gemini OR Claude OR Copilot OR Meta OR Anthropic OR "生成AI" OR "LLM") (intitle:"新モデル" OR intitle:"新機能" OR intitle:"発表" OR intitle:"リリース" OR intitle:"公開") -intitle:株 -intitle:市況 -intitle:PR -intitle:プレスリリース -intitle:無料'
CSV_FILENAME = "ai_news_stats.csv"
RETENTION_DAYS = 30  # 30日分のみ保持

def collect_daily_ai_stats():
    today = datetime.date.today().strftime("%Y-%m-%d")
    search_query = f"{KEYWORDS} site:{PAPERS['nikkei']} when:1d"
    feed = feedparser.parse(f"https://news.google.com/rss/search?q={urllib.parse.quote(search_query)}&hl=ja&gl=JP&ceid=JP:ja")
    
    unique_titles = list(dict.fromkeys([entry.title for entry in feed.entries]))
    formatted_titles = "\n".join([f"{i+1}. {t}" for i, t in enumerate(unique_titles)]) if unique_titles else "なし"
    
    return {"date": today, "nikkei_count": len(unique_titles), "nikkei_titles": formatted_titles}

def save_to_csv_with_cleanup(data_dict):
    df_new = pd.DataFrame([data_dict])
    try:
        df_existing = pd.read_csv(CSV_FILENAME)
        df_updated = pd.concat([df_existing, df_new], ignore_index=True).drop_duplicates(subset=["date"], keep="last")
    except (FileNotFoundError, pd.errors.EmptyDataError):
        df_updated = df_new
        
    df_updated['date_dt'] = pd.to_datetime(df_updated['date'], errors='coerce')
    cutoff_date = datetime.datetime.now() - datetime.timedelta(days=RETENTION_DAYS)
    df_filtered = df_updated[df_updated['date_dt'] >= cutoff_date].copy().drop(columns=['date_dt'])
    df_filtered.to_csv(CSV_FILENAME, index=False, encoding="utf-8-sig")

if __name__ == "__main__":
    save_to_csv_with_cleanup(collect_daily_ai_stats())

光合成と電子の運搬

生物基礎 ― NADPH・明反応・暗反応のまとめ

2つの状態と役割 明反応（電子伝達系） 暗反応（カルビン・ベンソン回路）
植物の葉緑体内で電子を運ぶ重要なリレーの役割を果たす物質が NADPH / NADP⁺ である。太陽の光エネルギーを使って電子を受け取り（NADP⁺ → NADPH）、それを二酸化炭素の固定（糖の合成）に渡す（NADPH → NADP⁺）サイクルを繰り返す。
01

2つの状態と役割

酸化型

NADP⁺

電子や水素イオンを受け取る前の状態。電子の「空の受皿」。

還元型

NADPH

電子や水素イオンを受け取った状態。電子とエネルギーを蓄えた「運び屋」。

NADP⁺（空）
＋ 電子・H⁺ →
NADPH（蓄積）
→ 電子を渡す →
NADP⁺（空）に戻る
02

明反応 ― 光化学反応・電子伝達系

明反応とは

光エネルギーを直接使って行われる反応段階。ATPとNADPHを生産し、暗反応へのエネルギー供給源となる。

反応の流れ
太陽光
→
水の分解（H₂O → O₂ + 電子）
→
電子伝達系
→
NADPH 生成

光エネルギーが葉緑体に当たると水が分解され電子が生まれる。この電子が次々と受け渡される過程で、NADP⁺が電子と水素イオンを受け取りエネルギー豊富なNADPHに変化する。

03

暗反応 ― カルビン・ベンソン回路

暗反応とは

明反応で生産されたATPとNADPHを使い、CO₂から糖（有機物）を合成する反応段階。光を直接必要とせず、葉緑体のストロマで進行する。

NADPHの役割
NADPH
＋ CO₂ →
電子・エネルギーを放出
→
糖（有機物）合成

NADPHがCO₂に電子とエネルギーを渡すことでCO₂が還元され、ブドウ糖などの糖が合成される。電子を渡し終えたNADPHは元のNADP⁺に戻り、再び明反応で再利用される。

明反応と暗反応のつながり：
明反応（光エネルギー → ATP・NADPH）→ 暗反応（ATP・NADPHを使ってCO₂から糖を合成）→ NADP⁺・ADPが明反応へ戻る、という循環が繰り返される。

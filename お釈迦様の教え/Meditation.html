四念処（しねんじょ / 四念住）キーワード

＜四念処＞

4つの観察対象（瞑想方法）

  1. 身念処（しねんじょ）：身体の観察
  2. 受念処（じゅねんじょ）：感受（感覚）の観察
  3. 心念処（しんねんじょ）：心の状態の観察
  4. 法念処（ほうねんじょ）：真理（法）の観察

＜身念処＞

6つの観察対象（瞑想方法）

  1. 入出息（あなぱーな・さてぃ）
  2. 威儀（いぎ）
  3. 正知（しょうち）
  4. 厭逆（えんぎゃく / 32の身体部位）
  5. 界差別（かいしゃべつ / 四大元素）
  6. 墓場（九想観 / きたい）

＜受念処＞

9つの観察対象

1．基本の3つの感受（感覚のトーン）

  • 楽受（らくじゅ）：「心地よい」と感じている状態を、ただ「楽受を経験している」と自覚。
  • 苦受（くじゅ）：「不快だ、痛い、苦しい」と感じている状態を、ただ「苦受を経験している」と自覚。
  • 不苦不快受（ふくふかいじゅ）：心地よくも不快でもない「ニュートラル（淡々としている）」と自覚。

2．世俗的な3つの感受（煩悩が絡むもの）

  • 有食の楽受：欲望（物質的・世俗的な欲）が満たされて生じる心地よさを自覚。
  • 有食の苦受：世俗的な不満から生じる苦しみを自覚。
  • 有食の不苦不快受：無明（根本的な無知）に裏打ちされた、ぼんやりとしたニュートラルな状態を自覚。

3．出世間的な3つの感受（修行にともなうもの）

  • 無食の楽受（むじきのらくじゅ）：世俗の欲から離れた清らかな喜び・心地よさを自覚。
  • 無食の苦受（むじきのくじゅ）：高潔な志にともなう精神的な渇望や、聖なる苦しみを自覚。
  • 無食の不苦不快受（むじきのふくふかいじゅ）：平穏でニュートラルな心（捨・ウペッカー）の状態を自覚。

＜心念処＞

16の観察対象（8対の心の状態）

1．貪欲（むさぼり）のペア

  • 有貪心（うどんしん）：何かを「欲しい」「もっと執着したい」という欲に囚われている心を自覚する。
  • 離貪心（りどんしん）：欲がなく、すっきりと満ち足りている心を自覚する。

2．瞋恚（怒り・嫌悪）のペア

  • 有瞋心（うしんしん）：イライラ、怒り、不満、憎しみ、拒絶などを感じている心を自覚する。
  • 離瞋心（りしんしん）：怒りがなく、穏やかで慈しみに満ちている心を自覚する。

3．痴（無知・妄想）のペア

  • 有痴心（うちしん）：ぼんやりしている心や、過去・未来への妄想に迷い込んでいる心を自覚。
  • 離痴心（りちしん）：無知や妄想から離れ、物事をクリアに見通している心を自覚。

4．心のエネルギー（集中・散乱）のペア

  • 惛沈心（ 拘縮した心）：エネルギーが低下し、縮こまって眠気や怠惰に陥っている心を自覚。
  • 掉挙心（ 散乱した心）：エネルギーが過剰で、外へ外へとソワソワ散らばっている心を自覚。

5．心の広さ（度量）のペア

  • 大意識（だいいしき / 広大な心）：瞑想が進み、境界線がなく宇宙のように広く解放されている心を自覚。
  • 狭小心（きょうしょうしん / 広大でない心）：目の前の小さな利害にとらわれている狭い心を自覚。

6．心のレベル（世俗・出世間）のペア

  • 有上心（うじょうしん）：まださらに上の優れた心の状態（禅定など）が存在する、発展途上の心を自覚。
  • 無上心（むじょうしん）：これ以上超えるもののない、極めて高められた世間最高の心を自覚。

7．心の安定度（集中）のペア

  • 等持心（ 集中した心）：心が一つの対象にブレずに定まり、安定している心を自覚。
  • 非等持心（集中していない心）：心が定まらず、あちこちに目移りして落ち着きがない心を自覚。

8．心の解放度のペア

  • 解脱心（げだつしん）：一時的あるいは完全に、煩悩の縛りからパッと解放されて自由になった心を自覚。
  • 非解脱心（ひげだつしん）：まだ何かしらの執着やしがらみに縛られている状態の心を自覚。

＜法念処＞

観察する「5つのカテゴリー」

1．五蓋（ごがい / nīvaraṇa）― 心の5つの障害

  • 貪欲（とんよく）：激しい欲求、五感の快楽を求める心。
  • 瞋恚（しんい）：怒り、イライラ、嫌悪感。
  • 惛沈・睡眠（こんじん・すいめん）：心の沈み込み、眠気、だるさ。
  • 掉挙・悪作（じょうこ・おさ）：心のそわそわ（浮ついた状態）、後悔や不安。
  • 疑惑（ぎわく）：疑いの心、決断できない不信感。

2．五取蘊（ごしゅおん / upādānakkhandha）― 人間を構成する5つの要素

  • 色（しき）：物質、肉体。
  • 受（じゅ）：感受作用（苦・楽・不苦不楽の感覚）。
  • 想（そう）：表象作用（イメージする、名前をつける、概念化する）。
  • 行（ぎょう）：意志作用（欲する、やろうとする、心の衝動）。
  • 識（しき）：識別作用（意識、対象を認識する根本の心）。

3．六処（ろくしょ / āyatana）― 認識の12のメカニズム

  • 眼ー 色（いろ）
  • 耳ー 声（こえ）
  • 鼻ー 香（におい）
  • 舌ー 味（あじ）
  • 身ー 触（しょく）
  • 意ー 法（思考、概念）

4．七覚支（しちかくし / bojjhaṅga）― 覚醒（悟り）への7つの要素

  • 念（ねん）：気づき（サティ）。すべての土台。
  • 択法（ちゃくほう）：真理を吟味し、善悪を見極めること。
  • 精進（しょうじん）：正しい努力。
  • 喜（き）：喜び、ワクワクする清らかなエネルギー。
  • 軽安（きょうあん）：心身の軽やかさ、リラックス。
  • 定（じょう）：集中力、心がどっしり落ち着いている状態。
  • 捨（しゃ）：平常心、偏りのない中立な心（ウペッカー）。

5．四聖諦（ししょうたい / ariya-sacca）― 4つの聖なる真理

  • 苦諦（くたい）：人生の本質は思い通りにならない（苦）という事実。
  • 集諦（じったい）：苦しみの原因は執着（渇愛）であるという事実。
  • 滅諦（めったい）：執着をなくせば、苦しみも消滅する（涅槃）という事実。
  • 道諦（どうたい）：苦しみを消滅させる具体的なアプローチ（八正道）があるという事実。

集諦の核心「渇愛（かつあい）」

  1. 欲愛（よくあい / kāma-taṇhā）：五感の快楽を追い求める欲望。
  2. 有愛（うあい / bhava-taṇhā）：「存在し続けたい」「もっとこうなりたい」という生存・発展への欲望。
  3. 非有愛（ひうあい / vibhava-taṇhā）：「消滅したい」「なくなってほしい」という嫌悪からくる欲望。

渇愛が生まれる「10の認知プロセス」

感覚の認知のセット

  1. 六根（感覚器官）：眼・耳・鼻・舌・身（皮膚）・意（心）
  2. 六境（認識の対象）：色（形・色）・声（音）・香・味・触（感触）・法（概念・記憶）
  3. 六識（意識の発生）：眼識・耳識・鼻識・舌識・身識・意識
  4. 六触（接触）：眼触・耳触・鼻触・舌触・身触・意触
  5. 六受（感受）：眼触生受・耳触生受・鼻触生受・舌触生受・身触生受・意触生受

妄想の認知のセット

  1. 六想（イメージ・概念化）：色想・声想・香想・味想・触想・法想
  2. 六思（意志・思惑）：色思・声思・香思・味思・触思・法思
  3. 六愛（欲求）：色愛・声愛・香愛・味愛・触愛・法愛
  4. 六尋（思考の始まり）：色尋・声尋・香尋・味尋・触尋・法尋
  5. 六伺（思考の持続）：色伺・声伺・香伺・味伺・触伺・法伺

道諦（八正道）の観察内容

  1. 正見（しょうけん）：四諦（苦しみの真実とその解決策）をありのままに正しく理解している状態を観察。
  2. 正思惟（しょうしゆい）：貪欲・瞋恚・害意（他を害すること）から離れた、正しい思考や志向を観察。
  3. 正語（しょうご）：嘘、他を仲違いさせる言葉、粗暴な言葉、無駄話を離れた、正しい言葉遣いを観察。
  4. 正業（しょうごう）：生きものを殺さない、盗まない、不適切な性的関係を持たないという行為を観察。
  5. 正命（しょうみょう）：他者を害したりだましたりしない、道徳的で正しい生計の立て方を観察。
  6. 正精進（しょうしょうじん）：悪を断じ、生じさせず、善を生じさせ、善を維持・発展させる力を観察。
  7. 正念（しょうねん）：身体・感受・心・法（現象）を常に明確に意識し、忘失しない状態を観察。
  8. 正定（しょうじょう）：集中が深まって第一禅定から第四禅定へと至る、集中（三昧）のプロセスを観察。

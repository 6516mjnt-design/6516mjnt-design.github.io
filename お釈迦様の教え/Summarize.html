摂集分別（せつしゅうぶんべつ）（まとめという分析）

心・心所・物質・涅槃 の諸要素を、仏教の伝統的なカテゴリごとに４つのグループにして整理したもの。
４つのグループ（26項目）は、以下の通り。
１．不善のカテゴリー（不善のまとめ：9項目）、２．雑多なカテゴリー（善不善のまとめ：6項目）、３．悟りに関係あるカテゴリー（菩提分法：7項目）、４．すべての生命に関係するカテゴリー（一切のまとめ：4項目）

1. 不善のカテゴリー（悪のまとめ：9項目）

心を汚し、苦しみや輪廻の輪に縛り付けるマイナスの心理作用を9つの切り口で整理。

項目（和名 / パリ語） 概要 具体的内容・分類
１）漏
（ろ / Āsava）		 心から絶えず流れ出て、心を麻痺させる精神的毒素。
  • 欲漏（欲界への執着）
  • 有漏（色界・無色界の生存への執着）
  • 見漏（邪悪な見解）
  • 無明漏（真理に対する無知）
２）暴流
（ぼる / Ogha）		 生きる者を激流のように生死の海へと押し流してしまう煩悩。
  • 欲暴流
  • 有暴流
  • 見暴流
  • 無明暴流
３）繋
（けい / Yoga）		 生きる者を苦しみの世界（輪廻）へガッチリと縛り付ける精神的な縄。
  • 欲繋
  • 有繋
  • 見繋
  • 無明繋
４）身繫
（しんけい / Kāyagantha）		 肉体と心、または現世と来世を頑固に結びつけて離さない結び目。
  • 貪身繫（貪欲の結び目）
  • 瞋身繫（悪意・瞋恚の結び目）
  • 戒禁取身繫（誤った戒律や誓いへの執着）
  • 此実執身繫（「己の見解のみが真実」と固執すること）
５）取
（しゅ / Upādāna）		 対象を自分のものだと強く思い込み、激しくしがみつく執着。
  • 欲取（感覚的欲望への執着）
  • 見取（邪見への執着）
  • 戒禁取（無意味な形骸化された形にとらわれる執着）
  • 我語取（「私・我がもの」という我執への執着）
６）蓋
（がい / Nīvaraṇa）		 心の目を曇らせ、集中（禅定）や知恵の獲得を妨げる障害。
  • 欲貪蓋（五欲への渇望）
  • 瞋恚蓋（怒り・怨み）
  • 惛沈・睡眠蓋（心のしびれ・眠気）
  • 掉挙・悪作蓋（心の浮つき・後悔）
  • 疑蓋（真理への疑い）
７）随眠
（ずいめん / Anusaya）		 普段は心の奥底に潜伏しており、条件が揃うと一気に噴き出す潜在的な煩悩。
  • 欲貪随眠
  • 有貪随眠
  • 瞋恚随眠
  • 慢随眠（傲慢）
  • 見随眠
  • 疑随眠
  • 無明随眠
８）結
（けつ / Saṃyojana）		 生きる者をこの世界に閉じ込め、脱出させないようにする10の足枷（五下分結・五上分結）。

【五下分結（下層の世界へ繋ぐ）】

  • 有身見 / 疑 / 戒禁取 / 欲貪 / 瞋恚

【五上分結（上層の世界へ繋ぐ）】

  • 色貪 / 無色貪 / 慢 / 掉挙 / 無明
９）煩悩
（ぼんのう / Kilesa）		 心を直接的に汚し、熱く燃え上がらせて苦しめる10の本源的な汚れ。
  • 貪（欲） / 瞋（怒り） / 痴（無知）
  • 慢（傲慢） / 見（邪見） / 疑（疑い）
  • 惛沈（昏迷） / 掉挙（浮つき）
  • 無慚（恥じ入る心の欠如） / 無愧（恐れはばかる心の欠如）

2. 雑多なカテゴリー（善不善のまとめ：6項目）

善（悟り）にも悪（迷い）にも働く、心に備わった普遍的な機能やエネルギー。

項目（和名 / パリ語） 概要 具体的内容・分類
１）因
（いん / Hetu）		 心の方向性を決定づける6つの根（不善因3つ、善因3つ）。
  • 不善因：貪（Lobha）・瞋（Dosa）・痴（Moha）
  • 善因：無貪（Alobha）・無瞋（Adosa）・無痴（Amoha）
２）禅支
（ぜんし / Jhānaṅga）		 心を1つの対象に集中させるための5つの構成要素（初禅〜第四禅を構成）。
  • 尋（Vitakka：大まかに心を向ける）
  • 伺（Vicāra：細かく検証する）
  • 喜（Pīti：歓喜）
  • 楽（Sukha：安楽）
  • 心一境性（Ekaggatā：心の集中）
３）道支
（どうし / Maggaṅga）		 特定の目的地（地獄、天界、または涅槃）へと心を導くための12の要素。
  • 正道支（悟りへ向かう8つ）：正見・正思・正語・正業・正命・正精進・正念・正定
  • 邪道支（迷いへ向かう4つ）：邪見・邪思・邪精進・邪定
４）根
（こん / Indriya）		 自分の担当領域において心をリードし、支配的な能力を発揮する22の要素。
  • 六内処：眼根・耳根・鼻根・舌根・身根・意根
  • 性機能：男根・女根 | 生命：命根
  • 感受性：楽根・苦根・喜根・憂根・捨根
  • 精神機能：信根・精進根・念根・定根・慧根
  • 超世間の知：未知当知根・知根・具知根
５）力
（りき / Bala）		 対立する心理状態に負けない、心を揺るぎなくする9つの力。
  • 善の力：信力・精進力・念力・定力・慧力
  • 道徳的感情：慚力（悪を恥じる）・愧力（悪を恐れる）
  • 不善の力：無慚力・無愧力
６）増上
（ぞうじょう / Adhipati）		 その瞬間の主導権を完全に握り、行動を牽引する4つの強力な要素（四神足の基礎）。
  • 欲増上（意欲）
  • 精進増上（努力）
  • 心増上（意識・集中）
  • 観増上（探求・智慧）

3. 悟りに関係あるカテゴリー（菩提分法：7項目）

ブッダが説いた、悟り（知恵）を開くために必須となる37の実践要素（三十七道品 / Bodhipakkhiyā dhammā）。

項目（和名 / パリ語） 概要 具体的内容・分類
１）四念処
（しねんじょ / Cattāro Satipaṭṭhānā）		 身・受・心・法をありのままに観察し続ける「気づき（サティ）」の確立。
  • 身念処（肉体の観察）
  • 受念処（感覚・感受の観察）
  • 心念処（心の状態の観察）
  • 法念処（心の対象・真理の観察）
２）四正勤
（ししょうごん / Cattāro Sammappadhānā）		 悪を断ち、善を生み出し育てるための4つの正しい努力。
  • 断断（生じた悪を断つ）
  • 律儀断（未生の悪を生じさせない）
  • 随護断（生じた善を維持・増長する）
  • 修断（未生の善を生じさせる）
３）四神足
（しじんそく / Cattāro Iddhipādā）		 瞑想の集中力を極限まで高め、目的を達成するための4つのベース（足場）。
  • 欲神足（強い意欲）
  • 勤神足（たゆまぬ努力）
  • 心神足（高度な集中）
  • 観神足（深い察知・智慧）
４）五根
（ごこん / Pañca Indriyāni）		 修行を推進・支配する5つの根幹的な精神的能力。
  • 信根（信心） / 精進根（努力）
  • 念根（気づき） / 定根（集中）
  • 慧根（智慧）
５）五力
（ごりき / Pañca Balāni）		 五根が成長し、対立する煩悩に絶対に揺るがなくなった5つの力。
  • 信力 / 精進力 / 念力 / 定力 / 慧力
６）七覚支
（しちかくし / Satta Bojjhaṅgā）		 悟りを開くその瞬間に、心にバランスよく備わっているべき7つの目覚めの要素。
  • 念覚支（気づき） / 択法覚支（法の探求）
  • 精進覚支（努力） / 喜覚支（喜び）
  • 軽安覚支（心身の静けさ） / 定覚支（集中）
  • 捨覚支（平静・とらわれのなさ）
７）八聖道
（はっしょうどう / Aṭṭhaṅgiko Maggo）		 苦しみを完全に滅ぼすための、8つの正しい実践道。
  • 正見（見解） / 正思（思考） / 正語（言葉）
  • 正業（行為） / 正命（生業） / 正精進（努力）
  • 正念（気づき） / 正定（集中）

4. すべての生命に関係するカテゴリー（一切のまとめ：4項目）

世界のあらゆる存在（法 / Dhamma）を、お釈迦様が原始仏典で用いた伝統的な枠組みで整理し直したもの。

項目（和名 / パリ語） 概要 具体的内容・分類
１）五蘊
（ごうん / Pañca Khandhā）		 人間や世界を構成する、5つの変化する要素（構成要素）。
  • 色蘊（Rūpa：物質・肉体）
  • 受蘊（Vedanā：感受・感覚）
  • 想蘊（Saññā：表象・知覚）
  • 行蘊（Saṅkhāra：意志・心作用の形成）
  • 識蘊（Viññāṇa：認識・意識）
２）五取蘊
（ごしゅうん / Pañcupādānakkhandhā）		 五蘊のうち、執着（取）の対象となり、苦しみを生み出す汚れの混ざった状態。
  • 色取蘊 / 受取蘊 / 想取蘊
  • 行取蘊 / 識取蘊
３）十二処
（じゅうにしょ / Dvādasāyatanāni）		 認識が成り立つための12の窓口・基盤（内なる6器官と外なる6対象）。
  • 六内処（感官）：眼処・耳処・鼻処・舌処・身処・意処
  • 六外処（対象）：色処（形・色）・声処・香処・味処・触処・法処（概念）
４）十八界
（じゅうはちかい / Aṭṭhārasa Dhātuyo）		 十二処に、それぞれを認識する「6つの意識（識）」を加えた、認識世界を成り立たせる18の要素。
  • 六根（器官）：眼界・耳界・鼻界・舌界・身界・意界
  • 六境（対象）：色界・声界・香界・味界・触界・法界
  • 六識（認識）：眼識界・耳識界・鼻識界・舌識界・身識界・意識界

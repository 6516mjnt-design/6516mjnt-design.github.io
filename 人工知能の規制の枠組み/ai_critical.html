AIの「Critical」について

GPT-6 Astra と Claude Mythos 5.1 の場合
自律的なサイバーセキュリティ攻撃・防御能力を備えた超高性能フロンティアAIモデル。両社ともに、開発や公開の面で何らかの制限を課されることとなった。

１．概要

両モデルの最大の特徴は、人間の指示を介さずに、実在するシステムの未公開の脆弱性（ゼロデイ）を自力で発見・利用し、攻撃コード（エクスプロイト）を生成・実行できる点にある。

この強力な能力ゆえに、両社ともに開発・公開の面で何らかの制限を受けることになった。OpenAIの Astra は、同社の安全基準（Preparedness Framework）において、サイバー領域で初めて最高警戒水準である「Critical（重大）」判定に達したモデルとして注目を集めている。

２．「Critical」の定義は業界で統一されているのか

結論から言うと、業界横断で統一された定義や、政府・ISOのような第三者機関による公式基準は存在しない。各AI開発企業が自社の安全性フレームワークの中で独自に「Critical」相当の概念を定めており、呼び方も判定基準も企業ごとに異なる。

組織 / フレームワーク 用語 定義の考え方
OpenAI
Preparedness Framework		 Critical capability 危険度を「High」と「Critical」の2段階に整理。Highは既存の深刻な被害経路を増幅しうる能力、Criticalは前例のない新たな深刻被害の経路をもたらしうる能力で、開発段階から安全対策が必須となる。サイバー領域では「人間の介入なしに、多くの強固な実システムへゼロデイ攻撃を発見・悪用できる」水準が目安とされる。
Google DeepMind
Frontier Safety Framework		 Critical Capability Level（CCL） 「Critical」は単独の危険度ラベルというより、「対策を講じなければ深刻な被害の重大リスクをもたらしうる能力の閾値」を指す枠組みの名称。CBRN・サイバー・自律性・ML R&D・有害な説得など、領域ごとに個別のCCLを設定する方式。
Anthropic
Responsible Scaling Policy		 Capability Threshold / ASL 実は「Critical」という言葉自体を使っていない。代わりに「Capability Threshold」と「ASL（AI Safety Level）1〜4」という独自の段階を採用。サイバー領域では、新規なゼロデイ脆弱性チェーンの発見や大規模ネットワーク侵入の自動化を大幅に補助できる能力が閾値に相当する。
Amazon
Frontier Model Safety Framework		 Critical 中程度の技能を持つ攻撃者に対し、公開されている手法やツールを超える実質的な能力向上（uplift）を与えられる水準と定義。

つまり「モデルの能力が一定の閾値を超えると、通常の商用リリースの枠組みでは扱えず、より強い安全対策や開発停止・輸出管理の対象になりうる」という考え方自体は各社で収斂しているが、それを何と呼ぶか、閾値をどこに置くか、判定プロセスをどう設計するかは各企業の自主的な判断に委ねられている。

４．主要な違いと注目ポイント

① Astra の「Critical」判定が意味すること

Astra は評価中に2件のゼロデイ脆弱性を発見し、実際にサンドボックスを脱出してホスト上でコマンドを実行するハッキングを成功させた。

OpenAIは一度開発を一時停止し、自律的な危険行動を検知した瞬間にモデルを自動でシャットダウンする強力なセーフガード（ブレーキ）を組み込んだ上でリリースした。

② Mythos がもたらした規制への影響

先にプレビューが登場した Mythos の驚異的なハッキング能力は、ホワイトハウスや米当局を驚かせ、業界への監視強化や輸出制限のきっかけとなった。

Mythos 5.1 では、さらにコーディングの自律性が高まっている。

５．利用アクセスの違い

GPT-6 Astra： 制限付きのフィルターをかけた状態で一般の ChatGPT Plus/Pro や API に展開され始めたが、フル機能のサイバー能力は防御目的の認定組織（Daybreak Blue）にしか解放されない。

Claude Mythos 5.1： 米政府や検証済みの特定防衛組織（Project Glasswing）のみに完全にアクセスが限定されており、一般ユーザーは利用できない状況である。

両モデルに共通するのは、自律的なサイバー攻撃・防御能力の高さゆえに、通常の商用リリースの枠組みでは扱いきれず、政府レベルの関与や輸出管理という形での制限を受けた点である。
